# Liste des écrans

Chaque écran a sa propre adresse (routage par hash). Paramètres utiles : `?lang=fr|ar|en` (langue) et `?embed=1` (masque le ruban, le plan et l’aperçu mobile — pratique pour les captures Figma).

Exemple : `index.html?lang=ar&embed=1#/acheteur`
